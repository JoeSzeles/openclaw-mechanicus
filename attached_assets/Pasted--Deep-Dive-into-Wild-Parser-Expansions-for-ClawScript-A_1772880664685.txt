#### Core Parser Expansions (Foundation Upgrades)
These make the parser smarter/more robust for wild commands.

1. **Macros / Functions (User-Defined)**  
   - Why: Let users define reusable blocks (e.g., custom indicators or alert templates) — like ProRealTime but with AI injection.  
   - Grammar: `DEF_FUNC name(params...) ... ENDFUNC` | Call: `name(arg...)`  
   - Parse: New `parseFunctionDecl()` (eat DEF_FUNC, params list, body until ENDFUNC).  
   - Generate: To JS functions inside the class.  
   - Example: `DEF_FUNC safe_buy(size, cond) IF cond THEN BUY size ENDIF ENDFUNC` | `safe_buy(1, RSI < 30)`  
   - Snippet:  
     ```js
     parseFunctionDecl() {
       this.eat('KEYWORD'); // DEF_FUNC
       const name = this.eat('IDENTIFIER').value;
       this.eat('PUNCTUATION'); // (
       const params = [];
       while (this.current().type === 'IDENTIFIER') {
         params.push(this.eat('IDENTIFIER').value);
         if (this.current().value === ',') this.eat('PUNCTUATION');
       }
       this.eat('PUNCTUATION'); // )
       const body = [];
       while (this.current().value.toUpperCase() !== 'ENDFUNC') {
         body.push(this.parseStatement());
       }
       this.eat('KEYWORD'); // ENDFUNC
       return { type: 'FunctionDecl', name, params, body };
     }

     // In generateStmt
     case 'FunctionDecl':
       let funcJs = `${indent}function ${stmt.name}(${stmt.params.join(', ')}) {\n`;
       stmt.body.forEach(s => funcJs += this.generateStmt(s, indent + '  '));
       funcJs += `${indent}}\n`;
       return funcJs;
     ```

2. **Async Chains (Promise Pipelines)**  
   - Why: For wild flows (e.g., web fetch → AI analyze → trade) without nested awaits.  
   - Grammar: `CHAIN expr1 THEN expr2 THEN expr3` (resolves sequentially).  
   - Parse: `parseChainExpr()` (eat CHAIN, expressions separated by THEN).  
   - Generate: To `expr1.then(r => expr2(r)).then(r => expr3(r))`.  
   - Example: `DEF result = CHAIN CLAW_WEB "news" THEN AI_QUERY "summarize" THEN ALERT result`  
   - Snippet:  
     ```js
     parseChainExpr() {
       this.eat('KEYWORD'); // CHAIN
       let chain = [this.parseExpression()];
       while (this.current().value.toUpperCase() === 'THEN') {
         this.eat('KEYWORD');
         chain.push(this.parseExpression());
       }
       return { type: 'ChainExpr', chain };
     }

     generateExpr(expr) {
       if (expr.type === 'ChainExpr') {
         let chainJs = this.generateExpr(expr.chain[0]);
         for (let i = 1; i < expr.chain.length; i++) {
           chainJs += `.then(r${i-1} => ${this.generateExpr(expr.chain[i])})`;
         }
         return chainJs;
       }
       // ... existing
     }
     ```

3. **Better Error Handling (Parser + Runtime)**  
   - Why: For wild scripts, catch more (e.g., undefined vars at parse time).  
   - Expand: In eat/parse, check variables exist for non-def (throw if undefined).  
   - Runtime: All generated code wrapped in try-catch with `AUTO_DEBUG` opt-in.  
   - Snippet: In `parseExpression()` add:  
     ```js
     if (expr.type === 'Identifier' && !this.variables.has(expr.value) && !this.isBuiltIn(expr.value)) {
       throw new Error(`Undefined variable: ${expr.value}`);
     }
     ```

#### Implementation Snippets (Parser / Generate)
Add to parser:

```js
case 'MARKET_NOMAD':
  return this.parseMarketNomad(); // Similar to CRASH_SCAN

case 'NOMAD_SCAN':
  return this.parseNomadScan();

case 'NOMAD_ALLOCATE':
  return this.parseNomadAllocate();

// Example parseNomadScan
parseNomadScan() {
  this.eat('KEYWORD'); // NOMAD_SCAN
  const category = this.parseExpression();
  let limit = 10;
  if (this.current().value.toUpperCase() === 'LIMIT') {
    this.eat('KEYWORD');
    limit = this.parseExpression();
  }
  this.imports.add('nomad');
  return { type: 'NomadScan', category, limit };
}

// In generateStmt
case 'MarketNomad':
  return `${indent}nomad.setEnabled(${stmt.state === 'ON'});\n`;

case 'NomadScan':
  return `${indent}const ${stmt.var || '_result'} = await nomad.scan(${this.generateExpr(stmt.category)}, { limit: ${stmt.limit} });\n`;
```
