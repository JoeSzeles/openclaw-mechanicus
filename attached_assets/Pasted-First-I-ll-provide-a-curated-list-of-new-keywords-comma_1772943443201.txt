### New ClawScript Keywords / Commands List

#### Time-Related Commands
- **TIME_IN_MARKET**  
  Grammar: `DEF time = TIME_IN_MARKET "position_id" [UNIT "ms/sec/min/hour/day"]`  
  Description: Calculates how long a position/trade has been open (from entry time to now). Unit optional (default ms).  
  Example: `IF TIME_IN_MARKET "deal123" UNIT "min" > 30 THEN EXIT REASON "Time limit"`  
  Wrapper:  
  ```js
  function timeInMarket(positionId, unit = 'ms') {
    const position = getPositionFromDB(positionId); // Assume DB query
    if (!position.entryTime) return 0;
    const diff = Date.now() - new Date(position.entryTime).getTime();
    const units = { ms: 1, sec: 1000, min: 60000, hour: 3600000, day: 86400000 };
    return diff / units[unit];
  }
  ```

- **TIME_SINCE_EVENT**  
  Grammar: `DEF time = TIME_SINCE_EVENT "event_time" [UNIT "sec/min"]`  
  Description: Time since a timestamp (e.g., last crash, news event).  
  Example: `IF TIME_SINCE_EVENT last_news_time UNIT "min" < 5 THEN PAUSE TRADING`  
  Wrapper: Similar to TIME_IN_MARKET, use Date.now() - event_time.

#### Market-Independent Scanning / Portfolio Commands
- **MARKET_SCAN**  
  Grammar: `DEF results = MARKET_SCAN "category" [CRITERIA "vol > X OR momentum > Y"] [LIMIT num]` (category: "forex/commodities/all")  
  Description: Scans IG markets for interesting instruments (vol, momentum, sentiment). Returns ranked array.  
  Example: `DEF top_fx = MARKET_SCAN "forex" CRITERIA "vol > 2*avg" LIMIT 5`  
  Wrapper:  
  ```js
  async function marketScan(category, criteria, limit = 10) {
    const code = `import statsmodels; # fetch IG list via proxy, apply criteria`;
    return await code_execution({ code }); // Return ranked epics
  }
  ```

- **PORTFOLIO_BUILD**  
  Grammar: `PORTFOLIO_BUILD FROM "scan_results" [NUM num] [SIZING "equal/kelly"] [MAX_RISK pct]`  
  Description: Builds/rebalances portfolio from scan, averages losses via diversification.  
  Example: `PORTFOLIO_BUILD FROM top_fx NUM 4 SIZING "kelly" MAX_RISK 20`  
  Wrapper: code_execution with PuLP for optimization.

- **PORTFOLIO_REBALANCE**  
  Grammar: `PORTFOLIO_REBALANCE [THRESHOLD dd_pct]`  
  Description: Auto-rebalance if drawdown hits threshold (swap low-performers).  
  Example: `IF dd > -10 THEN PORTFOLIO_REBALANCE`  
  Wrapper: Similar to build, uses statsmodels for corr/adjustment.

### Wrappers for ProRealTime-Specific Functions
All can be in `openclaw-prt.cjs` (imported when PRT_ keywords used). They use code_execution for calcs not in your indicators.cjs.

```js
// openclaw-prt.cjs (wrapper for PRT keywords)
async function prtAverage(period, series) {
  const code = `import numpy as np; return np.mean(series[-period:]) if len(series) >= period else None`;
  return await code_execution({ code, series: JSON.stringify(series) });
}

// Similar for others:
async function prtRSI(period, series) {
  // Use your calcRSI if available, else code_execution
}

async function prtCross(series1, series2) {
  const code = `import numpy as np; diff = np.diff(np.sign(series1 - series2)); return np.any(diff > 0)`;
  return await code_execution({ code, series1: JSON.stringify(series1), series2: JSON.stringify(series2) });
}

// ... stubs for all PRT_ commands (use statsmodels/numpy for regression, corr, std, sum, etc.)

module.exports = { prtAverage, prtRSI, prtCross /* all others */ };
```
