We'll build this right into ClawScript as a new command set: **`MARKET_NOMAD`** (cool name — nomadic market hunter). It scans, selects, and manages a portfolio automatically. Genius part: Uses your OpenClaw tools (web/X search for real-time vibes, code_execution for quick stats), variables for thresholds, and channels for alerts. Averages losses via diversification (e.g., cap 20–30% per instrument), correlation checks (drop if >0.8 corr), and auto-rebalance on signals.

### How It Works (High-Level)
- **Scan Phase**: Bot queries markets for "interesting" instruments (high vol for scalping, trends for following, oversold for reversion).
- **Selection**: Rank by score (momentum % + sentiment + vol surge), pick top N (e.g., 3–5).
- **Portfolio Management**: Allocate budget (e.g., equal-weight or Kelly), monitor DD per instrument, rebalance/swap if one lags.
- **Loss Averaging**: If one tanks (e.g., silver flash crash), the others (e.g., gold hedge) balance it. Auto-hedge inverses if corr negative.
- **Independent**: No fixed epics — bot varies based on conditions. Runs per tick or timer.

Realistic in your setup: Uses Lightstreamer for live data, DB for history, AI_QUERY for sentiment, code_execution for ranking math (numpy for corr/vol calcs).

1. **MARKET_NOMAD ON / OFF**

   Description: Toggle nomadic mode. Scans every X min, builds/rebalances portfolio.  
   Example: `MARKET_NOMAD ON MAX_INSTRUMENTS 4 SCAN_INTERVAL 15`

2. **SET NOMAD_*** (Variables for Tuning)  
   Grammar: `SET NOMAD_CRITERIA "momentum + vol + sentiment" [WEIGHTS "0.4,0.3,0.3"]`  
   - Other vars: `NOMAD_MIN_VOL_MULT = 1.5`, `NOMAD_MAX_CORR = 0.7`, `NOMAD_BUDGET_PCT = 25` (per instrument), `NOMAD_HEDGE_RATIO = 0.5` (for inverses).  
   Description: Customize scan/ranking.  

3. **NOMAD_SCAN**  
   Grammar: `DEF results = NOMAD_SCAN "category" [LIMIT num]` (category: "commodities", "forex", "indices", "all")  
   Description: Manual scan — returns ranked list [{epic, score, reason}].  
   Example: `DEF top_comms = NOMAD_SCAN "commodities" LIMIT 3`

4. **NOMAD_ALLOCATE**  
   Grammar: `NOMAD_ALLOCATE TO "epic_list" [SIZING "equal/kelly/vol_parity"]`  
   Description: Manually assign portfolio.  
   Example: `NOMAD_ALLOCATE TO top_comms SIZING "kelly"`

### Full Example ClawScript: Nomadic Portfolio Strategy

```clawscript
// NomadicPortfolio.cs

// Tune vars (change live)
SET NOMAD_CRITERIA "momentum + vol + sentiment" WEIGHTS "0.4,0.3,0.3"
SET NOMAD_MIN_VOL_MULT = 2.0  // Only high-vol plays
SET NOMAD_MAX_CORR = 0.75     // Diversify
SET NOMAD_BUDGET_PCT = 25     // 25% per instrument
SET NOMAD_HEDGE_RATIO = 0.5   // 50% inverse if possible
SET NOMAD_SCAN_INTERVAL = 30  // Min between scans

// Turn on nomadic mode
MARKET_NOMAD ON MAX_INSTRUMENTS 4

LOOP FOREVER  // Main loop
  // Manual scan if needed
  DEF candidates = NOMAD_SCAN "all" LIMIT 10

  // AI refine (optional)
  DEF refined = AI_QUERY "Rank these candidates for Brisbane trader: " + candidates TOOL "code_execution" ARG "code=rank_numpy.py"

  // Allocate if good
  IF refined.length >= 4 THEN
    NOMAD_ALLOCATE TO refined SIZING "vol_parity"  // Lower size for high-vol
    SAY_TO_SESSION "ceo" "New portfolio: " + refined[0].epic + " etc. Scores: " + refined.scores
    ALERT "Portfolio updated" TO "telegram" OPTIONS "chat_id=your_id"
  ENDIF

  // Check for crash/pump mid-run
  CRASH_SCAN ON

  // Wait for next scan cycle
  WAIT NOMAD_SCAN_INTERVAL * 60 * 1000
ENDLOOP
```

### How It Averages Losses
- **Diversification**: 4 instruments → if silver tanks, gold/AUD pump balances.
- **Rebalance**: Every 30 min, swap low-scorers (low momentum) for high — averages out losers.
- **Risk Caps**: Per-instrument budget % + corr firewall → no single wipeout.
- **Hedge Ratio**: Auto-sell inverse (e.g., if AUD long, hedge with USD short at 0.5 ratio).
- **Vol Parity Sizing**: Smaller size for volatile ones → averages exposure.
