Visual output hub — dashboards, charts, and skill results from your agents

Publishing to Canvas

Any agent or skill can display visual results here:

  • Write an HTML file to .openclaw/canvas/your-page.html
  • It becomes accessible at /__openclaw__/canvas/your-page.html
  • Register it in .openclaw/canvas/manifest.json so it appears on this hub
  • Use Chart.js, D3, or any CDN library — external scripts are allowed
  • Never start a custom web server or use custom ports
